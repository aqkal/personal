# Website audit, 13 September 2026

The audit covered the current working tree, preserving its existing development
work and the two-mode portfolio design. Changes were implemented locally.

## Implemented

- **Dependency security:** compatible updates reduced npm's report from 13
  vulnerable package entries (1 critical, 9 high, 3 moderate) to zero. Next.js
  moved from 16.2.10 to 16.3.5; Wrangler moved from 4.107.0 to 4.131.1.
  Transitive fixes include PostCSS, Sharp, Undici and YAML parsers. The
  [Next.js security release](https://nextjs.org/blog/august-2026-security-release)
  documents the critical framework fixes. CI now fails on high or critical
  dependency findings.
- **Cloudflare runtime:** upgraded OpenNext to 1.20.6 to fix Windows Turbopack
  chunk paths. Configured its read-only static-assets cache after runtime tests
  exposed 404s for prerendered project and blog slugs. This uses the existing
  asset binding without an additional service. Hashed JS/CSS files now use
  immutable caching. CI checks actual HTTP responses from both runtimes.
- **Initial page and recovery:** the homepage now sends an identity heading,
  main landmark, resume and blog links in its server HTML. The previous boot
  frame was empty. Visitors without JavaScript receive useful navigation.
  A page error boundary provides retry and onward links.
- **Navigation and search metadata:** old About, Experience and Projects URLs
  lead directly to the relevant portfolio section, regardless of a stored game
  preference. Contact, resume and case-study pages have their own canonical
  URLs. Site URLs are normalized; sitemap entries are unique; RSS URLs are
  escaped. The game Work drawer's Skills link opens the portfolio section.
- **Accessibility and mobile layout:** corrected section numbering, responsive
  sticky labels, focus states and modal focus filtering. The mobile header no
  longer overlaps the opening location label. Reveal and Counter retain useful
  server output; the highlights ticker pauses on keyboard focus. Loading states
  announce progress and context-loss recovery has alert-dialog semantics.
- **Contact reliability:** the endpoint limits actual streamed request bytes,
  applies deadlines to external calls, rejects non-success captcha responses
  and validates recipient configuration. The form retains input on failure,
  reports captcha problems, cleans up widgets, and allows enough time for both
  upstream calls. Production without a public captcha key offers direct email.
  Automated tests mock every external request and send no real messages.
- **Game correctness:** fixed travel while the canvas is paused, a travel timer
  race, route failure feedback, panel/audio event consistency, and shadow size
  filtering under scaled parent objects. Removed unused duplicate keyboard
  listeners. No additional lighting or postprocessing was introduced.
- **Requested building move:** BucklerX is now centered at `(25, -37)`, behind
  Qualia and DSR. Its model, facade label, entrance `(25, -33.4)`, colliders,
  approach path, route destinations, district label and map agree. Updated
  Blender sources and regenerated the campus assets and metadata.
- **Asset portability:** compressed GLBs are explicit gzip files, decoded by a
  shared loader. This avoids Cloudflare double transport encoding and preserves
  compressed transfers. The same loader and cache serve the portfolio portrait
  and campus models.

## Follow-up game fixes

- Shoreline rails are authored in Blender with 147 collision panels, preserving
  the ferry and bridge openings. Scooter geometry cleanup now survives React
  development lifecycle replay, which caused missing wheels on port 3000.
- Scooter and cart drifting use lateral momentum. Braking overrides throttle,
  so holding Space spends speed and stops the vehicle. Skid marks use one
  bounded mesh; rubber squeal and scrub follow actual slip. Default music is
  30 percent, while saved preferences are retained.
- Building collision exports include the closed glass fronts, doors and raised
  bases omitted by the old allowlist. Vehicle bounds include the cart canopy
  and scooter rider, and vehicles can retreat safely after blocked turns.
- Port 3010 was a separate production preview; it has been stopped. Port 3000
  is the active development server and includes the wheel lifecycle fix.
- Supported PCF shadows replace the deprecated soft-shadow setting. Remaining
  Clock and Rapier initialization notices originate in installed dependencies;
  no warning suppression or dependency patches were added.
- Follow-up checks passed for building sweeps, finite drift, skid-buffer reuse,
  scooter lifecycle cleanup, shoreline boundaries, and offline audio output.
  The player visibly stopped outside the Qualia base under continued forward
  input. Final native and Cloudflare builds both passed the ten-page HTTP suite.

## Verification

- Full ESLint and TypeScript checks passed.
- Content validation passed, with the known profile placeholders retained.
- Mocked contact endpoint checks passed.
- World validation passed, including 60 routes and BucklerX placement checks.
- Physics, camera follow, travel presentation and frame CPU regressions passed.
- Collision verification compared 363,337 positions; authored assets validated.
- Native production build and HTTP checks passed for all 10 indexed pages,
  initial HTML, canonical links, redirects, headers, feeds, 404 handling and
  compressed campus delivery.
- Cloudflare build and runtime checks passed for the same routes and transport contract,
  including populated prerender entries and gzip file contents. Build success
  alone is no longer the only check for either host.
- Browser checks verified the mobile portfolio, BucklerX fast travel, entrance
  interaction, and forward/backward modal keyboard focus. No runtime errors
  were observed in those interactions. The shadow-map setting now explicitly
  uses supported PCF filtering; the upstream Three.js Clock notice is tracked separately.
- Wrangler's generated preview bundles are excluded from ESLint, preventing
  local runtime checks from making subsequent lint runs scan generated code.

OpenNext on Windows still logs package-copy and upstream bundler warnings.
The generated package files were inspected, and runtime checks are used to
verify the resulting Worker rather than treating its exit status alone as
evidence that every route works.

## Deferred by request and deployment configuration

The display name and social URLs remain placeholders at the owner's request.
Set the actual site URL and contact/captcha credentials when preparing a public
deployment. This audit did not publish or deploy the site. Browser checks used
the local production server; they are not an exhaustive device compatibility
or accessibility certification.
